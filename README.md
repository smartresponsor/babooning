# Babooning 🐒

Mobile-first static game deployed directly from `master` to GitHub Pages. No build or GitHub Actions needed for the current HTML/CSS/JS MVP.

## Photo sources and attribution

The game rotates photographs served by Wikimedia Commons, not bundled local assets yet. Each linked source page identifies its photographer, applicable Creative Commons license and attribution conditions. Copyright remains with the original authors. Browser `object-fit: cover` crops the images visually; no originals are modified in this repository.
